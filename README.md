## Featured Project

### MMI Waveguide Simulation using varFDTD

本项目使用 Ansys Lumerical varFDTD 对多模干涉器件 MMI 波导进行仿真。

项目内容包括：

- 建立 MMI 波导仿真模型
- 扫描 MMI 区域长度
- 分析不同输出端口的透射率变化
- 可视化电场分布
- 研究多模干涉和自成像现象

Project link:
